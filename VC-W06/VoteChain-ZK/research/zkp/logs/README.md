# VC-W03 ZKP Raw Logs

This directory is intentionally free of fabricated benchmark numbers.

Successful execution of:

```bash
npm run zk:poc
```

writes `semaphore-poc-result.json` with measured proof-generation time, off-chain verification time, proof JSON size, root and nullifier behavior.

Successful local execution of:

```bash
npm run zk:e2e
```

writes `local-zk-e2e-result.json` with real deployment addresses, same-wallet voting evidence, rejection checks, gas receipts and proof timing/size.

The current worker runtime could not install the pinned Semaphore packages and has no Foundry/Anvil, so those measurement files are not present here. They must be generated by the documented commands rather than synthesized.
